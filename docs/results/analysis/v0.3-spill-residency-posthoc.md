# Spill frame residency correction: CPU replay and legacy microbenchmark recheck

**Provisional, post-hoc.** The microbenchmark endpoints use archived legacy
data. This recheck leaves the frozen v0.2 conclusions in force.
[Preregistration](v0.3-spill-residency-plan.md)

## Core change

At phase entry the simulator now selects the spill charge using the
number of resident CTAs on that SM after same-timestamp completions
and refills. The frame footprint goes from the hardware allowance to
the realized count times threads per CTA times bytes per thread. For
the recheck kernel that is 128 KiB instead of 1 MiB. The script still
subtracts the matched zero-reload prediction and uses the same
profile, spill scope, per-thread traffic, and shared-memory carveout.
The charge is held through the phase. The model retains the existing
persistent L2 spill-pressure policy, initialized using the largest
realized first-wave residency.

The Rust regression uses an L2 test double to make the spill split
sensitive to resident threads. It checks one CTA, an uneven first wave,
a full first wave, and the extra CTA in a sparse tail.

## Legacy microbenchmark decision

The four nonzero batched `l1_boundary` reload counts are 8, 32, 68,
and 128 per thread. All comparisons use the same measured extra time
per step with the corresponding zero-reload case subtracted. The
unchanged mechanisms (closed-loop DRAM, L2 and MMA, miss merging,
both port-floor checks, the RTX 4070 dependent chain and the LSU
issue check) reproduce every predicted value. Their IR carries no
spill charge.

| Device | Signed median error, base / candidate | Median absolute error, base / candidate | MAPE, base / candidate |
| --- | ---: | ---: | ---: |
| GB10 | +209.6% / +67.6% | 209.6% / 67.6% | 183.8% / 54.9% |
| RTX 4070 | +70.7% / +38.0% | 70.7% / 38.0% | 67.2% / 35.0% |

Both devices meet all three registered legacy error criteria. The
remaining positive error includes the estimated local pipe rate and
the provisional reload latency. The legacy source lacks the five
independent long-launch rounds and gate telemetry needed to establish
current capture quality. Rules 1 through 3, thermal stability and
host or desktop quiet therefore have no current-protocol pass for
these inputs. The first full GB10 attempt voided six of the seven
spill rounds on rule 1 and supplies no endpoint here. The carveout
diagnostic tested the driver-carveout hypothesis and remains separate
from the recheck. [Baseline rows](v0.3-mechanism-recheck-baseline.json)
